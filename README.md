# Plotting

A guide to preparing engineering figures: visual perception, color and colormaps,
choosing the encoding, axes, fonts, transparency, and figures inside a document.
By Dima Bykhovsky, licensed CC BY-NC-SA 4.0.

- **Read online:** https://bykhov.github.io/plotting/
- **PDF:** https://bykhov.github.io/plotting/plottingc.pdf

Originally an appendix of *Data-Driven Time-Series Prediction*
(https://bykhov.github.io/data-driven/).

## Building

The PDF and the HTML come from one LaTeX source through
[lwarp](https://ctan.org/pkg/lwarp).

```bash
pdflatex --shell-escape plotting    # PDF (run twice for references)
lwarpmk html                        # HTML: index.html + node-*.html
compress.bat                        # plotting.pdf -> plottingc.pdf (pdfsizeopt)
```

Every figure in `figs/` is generated by the `.py` script of the same name
(numpy + matplotlib); run it from inside `figs/`.

## Deployment

Build locally, commit the HTML, `lwarp.css` and `plottingc.pdf`, and push to
`main`. `.github/workflows/pages.yml` copies the web files to the `gh-pages`
branch, which GitHub Pages serves.
