This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

"Plotting" by Dima Bykhovsky: a standalone guide to preparing engineering figures, split
out of the *Data-Driven Time-Series Prediction* book (`../data-driven`). One LaTeX source
produces a PDF and a paginated HTML site through **lwarp** (MathJax for math). Document
class is `scrartcl` (KOMA-Script); each `\section` becomes one HTML page.

## Build Commands

```bash
pdflatex --shell-escape plotting    # build PDF (twice to settle references)
lwarpmk html                        # build HTML (index.html + node-*.html)
lwarpmk again                       # force recompile when only content.tex changed
compress.bat                        # plotting.pdf -> plottingc.pdf, the deployed PDF
```

`lwarpmk.conf` is generated by lwarp from the job name (`sourcename = plotting`). Never
compile with `-jobname`, it rewrites that file.

The HTML build has traps that silently corrupt the output (poppler `pdftotext` requirement,
`-jobname` vs `lwarpmk.conf`, tabular column types, sub-figure centering). Load the
`/html-latex-fixes` skill before building or debugging HTML output. The poppler
`pdftotext` is MiKTeX's: `export PATH="/c/Users/dmitrby/AppData/Local/Programs/MiKTeX/miktex/bin/x64:$PATH"`.

## Files

- **plotting.tex** - preamble, title page, `\input{content}`
- **content.tex** - the whole text
- **conf_math.tex** - math macros; every macro is mirrored with `\CustomizeMathJax{}` for HTML
- **config2.tex** - headers/footers and the `L`/`C`/`R` column types (with `\HTMLnewcolumntype` twins)
- **lwarp_academic.css** - hand-maintained HTML theme, `@import`s the generated `lwarp.css`; CSS-only fixes need no rebuild
- **figs/** - `plot_*.py` scripts and their PDF/SVG/JPEG outputs, `challenger_thiokol.jpg`
- **.github/workflows/pages.yml** - on push to `main`, copies HTML, CSS, `plottingc.pdf` and `figs/` SVGs to `gh-pages`

Site: https://bykhov.github.io/plotting/

## Conventions

- Tables: booktabs rules only, sorted by the quantity of interest (see the Tables appendix, `tables.tex`, which the document's own tables must obey). Decimal-aligned columns use `N{2.1}` (fixed decimals) or `P` (one integer digit, varying decimals), not a bare siunitx `S`: both are `S` in the PDF with HTML twins that align correctly (plotting.tex). Loading siunitx makes lwarp define unit macros such as `\pm` (picometre) in MathJax; plotting.tex restores `\pm`, so check any other unit-named macro (`\mm`, `\ms`, ...) the same way before using it in math.
- Environments: `goal`, `box_red` (hard errors), `box_yellow` (caveats), `box_blue` (clarifications); an optional `[Title]` gives the box a title bar.
- Labels: `sec-app-plot-*`, `fig-plot-*`, `eq-plot-*`, `tab-plot-*`. Equations, figures and tables are numbered within sections.
- `\includegraphics{name}` without directory or extension: `\graphicspath{{figs/}}` resolves it, pdflatex picks `.pdf`, lwarp picks `.svg`. Include figures at natural size, no `width=` (it rescales the text too).
- Python figures: Times New Roman, 10 pt, `figsize` width at most 7 in, save PDF + SVG + JPEG (300 dpi, `bbox_inches='tight'`). See **figure-fonts.md** before changing any font size.
- Prose: American English; no em-dashes.
